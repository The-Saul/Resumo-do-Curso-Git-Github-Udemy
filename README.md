# Resumo-do-Curso-Git-Github-Udemy
Este é um repositório simples para mandar o link ao professor John, do curso Desenvolvimento Web Back-End da faculdade, nele terá o resumo dos cursos que ele passou na Udemy: "Git: Become an Expert in Git & GitHub in 4 hours!" e "Git e Github para iniciantes".

As Anotações foram todas feitas no Notion, eu só exportei em formato HTML e modifiquei no VSCode o que foi necessário, ajeitei umas coisas que não estavam aparecendo no site, nele tem partes principalmente de CSS, para deixar o texto o mais fiel possível ao que estava no Notion e as partes de HTML que tem, são as partes necessárias para que a página funcione e o conteúdo com algumas classes de CSS também. 
Achei muito interessante a forma como tudo isso foi organizado automanticamente pelo Notion, por mais que eu tenha modificado as pastas a localização das coisas e um pouco do html e css, foi surpreendente como o notion transformou tudo aquilo em um HTML bem escrito.
